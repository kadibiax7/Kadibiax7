# 🛡️ Cybersecurity Projects

### [Home SOC Security Monitoring with Splunk](https://github.com/kadibiax7/Splunk-home-SOC-lab) — In Progress
Configured a Windows 11 endpoint to forward Security Event Logs to Splunk Enterprise on Ubuntu. Used SPL to investigate failed logons and created a dashboard panel to count them. This demonstrates log collection, authentication analysis, and basic SIEM monitoring; the successful-logon panel is still in progress.

### [Home Network Security Assessment with Nmap](https://github.com/kadibiax7/Home-Network-Security-Assessment-Nmap-)
Used Nmap on my own home network to discover devices, scan ports, and identify services. Documented a printer exposing web administration on ports 80 and 8080 and recommended disabling the redundant interface to reduce its attack surface.




### [Gekian Boutique — Womenswear Storefront](https://github.com/kadibiax7/gekian-boutique) — In Development

**[Live website](https://gekian-boutique--gekain.us-central1.hosted.app)** · [Source code](https://github.com/kadibiax7/gekian-boutique)

A storefront project using Next.js, TypeScript, Tailwind CSS, and Firebase. The README describes product browsing, filtering, product detail pages, and a local shopping bag, with ongoing Firestore catalog integration. Checkout, ordering, authentication, and inventory reconciliation remain unimplemented.
